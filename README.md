# Algorithm Visualizer

A fully interactive web app to visualize 10+ algorithms in real time including Merge Sort, Quick Sort, Heap Sort, BFS, DFS, Dijkstra's, and A*.

## Features
- **Sorting Visualizations**: Bubble, Selection, Insertion, Merge, Quick, and Heap sorts.
- **Graph Traversals**: Breadth-First Search (BFS) and Depth-First Search (DFS).
- **Pathfinding**: Dijkstra's Algorithm and A* Search.
- **Battle Mode**: Run two algorithms side-by-side to visually compare Big-O complexity in real-time.
- **Real World Data**: Sort real-world datasets like building heights and country populations.
- **Guess the Algorithm**: A fun quiz mode where an algorithm runs blindly and you guess which one it is.
- **Live Complexity & Pseudocode**: Watch code execute line-by-line with dynamic complexity graphing.
- **Shareable URLs**: Easily share specific visualizer states using encoded query parameters.
- **Zero Dependencies**: 100% Vanilla HTML, CSS, and JS.

## Run Locally
You can run the project locally simply by opening `index.html` in your web browser. 
No build steps or dependency installation required!
